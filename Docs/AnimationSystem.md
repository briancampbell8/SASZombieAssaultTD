# Animation System

## Overview
Animations bring life to enemies, turrets, soldiers, and effects. The system uses sprite sheets and frame timing.

---

## Animation Types

### Enemy Animations
- Walk cycle
- Attack animation
- Death animation
- Special animations (split, summon, phase)

### Turret Animations
- Firing frames
- Idle frames
- Elemental effects (flame, lightning, acid)

### Soldier Animations
- Firing
- Idle
- Hurt
- Death

### Effect Animations
- Explosions
- Fire
- Lightning arcs
- Acid splashes

---

## Timing Rules
- Frame duration defined per animation
- Looping for movement and idle
- One-shot for explosions and deaths
