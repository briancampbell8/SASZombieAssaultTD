# Turret and Soldier Behavior

## Turrets

### Vickers Turret
- Continuous bullet stream
- Low cost, fast placement
- Effective early-game turret

### MGL Turret
- Automated grenade launcher
- AoE splash damage
- Strong against clustered zombies

### Special Turret
- Multi-mode turret:
  - Lightning
  - Acid
  - Flame
- High-tier upgrade path
- Most versatile turret in the game

---

## SAS Soldiers

### Machine Gun SAS
- Continuous fire
- Vulnerable unless placed on rooftops
- Good for cleanup and support

### Sniper SAS
- Longest range in the game
- Ideal for large zombies
- High single-target damage

---

## Deployables

### Sandbag
- Path manipulation
- Creates killboxes
- Blocks zombies but not bullets

### Barbed Wire
- Damage-over-time
- Slows zombies
- Cheap and effective

### Frag Grenade
- Burst AoE
- Good for emergencies
- Useful for clearing leaks
