# UI Design

## Overview
The UI system provides the player with battlefield awareness, controls, and feedback. This document defines the layout and behavior of all UI elements.

---

## Core UI Elements

### HUD
- Lives counter
- Cash counter
- Wave indicator
- Achievement counter

### Item Bar
- Turrets
- Soldiers
- Deployables
- Premium items (free)

### Tooltip System
- Shows cost
- Shows description
- Shows cooldowns (premium items)

### Alerts
- “Wave Incoming”
- “Boss Approaching”
- “Turret Destroyed”
- “Ruin Detected”

---

## UI Layout Principles
- Bottom bar for items
- Top-left for player stats
- Top-right for wave info
- Center-screen alerts for major events

---

## UI Assets
- Icon sprites for all items
- Font atlas
- Button states (normal, hover, pressed)
- Alert banners
