# Upgrade System

## Overview
Turrets and soldiers can be upgraded to improve damage, range, and special effects.

---

## Upgrade Tiers

### Vickers Turret
- Level 1: Base stats
- Level 2: Increased fire rate
- Level 3: Increased damage

### MGL Turret
- Level 1: Base stats
- Level 2: Larger explosion radius
- Level 3: Higher damage

### Special Turret
- Level 1: Base elemental mode
- Level 2: Stronger elemental effects
- Level 3: Faster mode switching + higher damage

---

## Upgrade Rules
- Upgrades cost cash
- Upgrades apply instantly
- Upgrades persist until turret is destroyed
