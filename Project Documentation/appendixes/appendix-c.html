Appendix C: Debugging Guide

Comprehensive Debugging Techniques

Debugging Tools Overview

Pro Tip: Enable debug mode in configuration to access all debugging features and logging levels.

Available Debug Tools

  • Console Logger: Real-time logging system with multiple levels
  • Performance Profiler: Frame rate and memory usage tracking
  • Entity Inspector: Live entity component viewing
  • Physics Debugger: Collision shape and force visualization
  • AI Behavior Tracer: Pathfinding and decision tree debugging
  • Animation Debugger: State machine and blend tree visualization

Logging System

Log Levels

// Log levels in order of severity public enum LogLevel { Trace, // Detailed information for debugging Debug, // Debug information Info, // General information Warning, // Warning messages Error, // Error messages Critical // Critical errors } // Usage examples Logger.Trace("Entering Update method"); Logger.Debug($"Entity {entity.Id} position updated"); Logger.Info("Game started successfully"); Logger.Warning("Low memory detected"); Logger.Error("Failed to load asset"); Logger.Critical("System crash detected");

Structured Logging

// Structured logging with context Logger.Info("Entity spawned", new { EntityId = entity.Id, EntityType = entity.Type, Position = entity.Position, Timestamp = DateTime.UtcNow }); // Performance logging using var timer = Logger.StartTimer("EntityUpdate"); // ... entity update logic timer.Stop();

Performance Debugging

Frame Rate Analysis

// Enable performance profiling Debug.EnableProfiling(); // Monitor specific systems Debug.ProfileSystem("AnimationSystem", () => { animationSystem.Update(deltaTime); }); // Custom performance markers Debug.BeginSample("EnemyAI"); aiSystem.Update(); Debug.EndSample(); // Get performance report var report = Debug.GetPerformanceReport(); Console.WriteLine($"Average FPS: {report.AverageFPS}"); Console.WriteLine($"Frame Time: {report.AverageFrameTime}ms");

Memory Debugging

// Memory tracking Debug.EnableMemoryTracking(); // Take memory snapshot var snapshot = Debug.TakeMemorySnapshot(); // Analyze memory usage var analysis = Debug.AnalyzeMemory(snapshot); foreach (var category in analysis.Categories) { Console.WriteLine($"{category.Name}: {category.Size} bytes"); } // Detect memory leaks var leaks = Debug.DetectMemoryLeaks(); if (leaks.Count > 0) { Logger.Warning($"Memory leaks detected: {leaks.Count}"); }

Entity System Debugging

Entity Inspector

// Get all entities var entities = entityManager.GetAllEntities(); // Inspect specific entity var entity = entityManager.GetEntity(entityId); Console.WriteLine($"Entity {entity.Id}:"); Console.WriteLine($" Components: {entity.ComponentCount}"); // List all components foreach (var component in entity.Components) { Console.WriteLine($" - {component.Type}: {component.Value}"); } // Watch entity changes Debug.WatchEntity(entityId, (entity, change) => { Logger.Debug($"Entity {entity.Id} changed: {change}"); });

System Debugging

// Enable system debugging Debug.EnableSystemDebugging(); // Trace system execution Debug.TraceSystem("MovementSystem"); // Get system statistics var stats = Debug.GetSystemStats("MovementSystem"); Console.WriteLine($"Processed entities: {stats.EntityCount}"); Console.WriteLine($"Execution time: {stats.ExecutionTime}ms");

Physics Debugging

Collision Visualization

// Enable physics debug drawing Debug.EnablePhysicsDebug(); // Draw collision shapes Debug.DrawColliders(true); // Draw collision contacts Debug.DrawContacts(true); // Draw forces and velocities Debug.DrawForces(true); // Custom debug drawing Debug.DrawSphere(position, radius, Color.Red); Debug.DrawLine(start, end, Color.Green); Debug.DrawBox(center, size, Color.Blue);

Raycast Debugging

// Debug raycast with visualization var hit = Debug.Raycast(origin, direction, maxDistance); if (hit.HasValue) { Debug.DrawHitPoint(hit.Value.Point, Color.Red); Debug.DrawHitNormal(hit.Value.Point, hit.Value.Normal, Color.Yellow); } // Continuous raycast debugging Debug.ContinuousRaycast(origin, direction, maxDistance, (hit) => { Logger.Debug($"Raycast hit: {hit.EntityId} at {hit.Point}"); });

AI Debugging

Pathfinding Visualization

// Enable AI debugging Debug.EnableAIDebugging(); // Draw navigation mesh Debug.DrawNavigationMesh(true); // Draw paths Debug.DrawPaths(true); // Trace pathfinding Debug.TracePathfinding(entityId); // Get pathfinding statistics var stats = Debug.GetPathfindingStats(); Console.WriteLine($"Path calculations: {stats.PathCalculations}"); Console.WriteLine($"Average path length: {stats.AveragePathLength}");

Behavior Tree Debugging

// Enable behavior tree debugging Debug.EnableBehaviorTreeDebugging(); // Trace behavior execution Debug.TraceBehavior(entityId); // Get behavior tree state var state = Debug.GetBehaviorTreeState(entityId); Console.WriteLine($"Current node: {state.CurrentNode}"); Console.WriteLine($"Node stack: {string.Join(" -> ", state.NodeStack)}"); // Visualize behavior tree Debug.DrawBehaviorTree(entityId);

Animation Debugging

Animation State Visualization

// Enable animation debugging Debug.EnableAnimationDebugging(); // Draw animation states Debug.DrawAnimationStates(true); // Draw blend trees Debug.DrawBlendTrees(true); // Trace animation events Debug.TraceAnimationEvents(entityId); // Get animation statistics var stats = Debug.GetAnimationStats(entityId); Console.WriteLine($"Current animation: {stats.CurrentAnimation}"); Console.WriteLine($"Playback time: {stats.PlaybackTime}"); Console.WriteLine($"Is looping: {stats.IsLooping}");

Common Debugging Scenarios

Performance Issues

Symptoms: Low frame rate, stuttering, memory leaks

Debugging Steps:

  1. Enable performance profiling
  2. Check system execution times
  3. Analyze memory usage patterns
  4. Identify bottleneck systems
  5. Optimize hot paths

Entity Issues

Symptoms: Missing entities, incorrect component data

Debugging Steps:

  1. Use entity inspector to verify entity state
  2. Check component data integrity
  3. Verify system execution order
  4. Trace entity lifecycle events

Physics Issues

Symptoms: Objects passing through walls, incorrect collisions

Debugging Steps:

  1. Enable physics debug drawing
  2. Verify collision layers and matrices
  3. Check collider shapes and positions
  4. Analyze collision contact points

AI Issues

Symptoms: Enemies not moving, incorrect pathfinding

Debugging Steps:

  1. Enable AI debugging visualization
  2. Check navigation mesh integrity
  3. Trace pathfinding calculations
  4. Analyze behavior tree execution
